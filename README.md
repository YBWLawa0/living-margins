# 众生行记

> 一套连接实体书、手机与智能页边屏幕的阅读系统，让读者在不离开纸质阅读的同时，看见并回应每一篇书页上前人走过的痕迹。

## 项目简介

图书馆保存了大量书籍，却几乎没有保存人们经过这些书页时留下的思想。

不同读者可能在同一句话前停留、提出相似问题，也可能产生完全不同的理解，但这些经历通常彼此不可见。纸质批注只能留在个人书本中，不适合公共馆藏；网络书评又大多围绕整本书展开，无法让读者在翻到某一页的当下遇见与之相关的观点。

当读者想记录或查阅想法时，往往需要离开书页、拿起手机、打开应用、搜索书籍并定位页码，纸质阅读的连续性也随之被打断。

**众生行记**尝试补上纸质阅读缺失的这一层：让实体书不再只是静态馆藏，而成为一种会随阅读不断积累、让不同时空的读者在具体书页上意外相遇的知识媒介。

## 我们想解决什么

1. **纸质书不能承载公共批注**：公共图书不能随意书写，个人笔记又无法自然流向下一位读者。
2. **阅读社区与书页脱节**：传统书评围绕整本书展开，读者很难在阅读现场遇见与当前页面相关的观点。
3. **手机记录打断阅读**：解锁手机、打开应用、搜索书籍和定位页码，会破坏纸质阅读原本的沉浸感。
4. **图书馆难以保存阅读过程**：图书馆保存了书，却没有保存读者在书中产生的问题、联想与理解。

## 系统如何工作

```text
实体书
  ↓ 手机摄像头持续感知
封面识别 / 页码识别
  ↓
云端匹配书籍、页面与公共批注
  ↓
智能页边屏幕呈现当前页的阅读痕迹
  ↕
赞同 / 不赞同 / 灵感 / 批注 / 审核
```

手机负责视觉感知，云端负责识别与数据组织，智能页边屏幕负责低干扰呈现。数字内容附着在书页旁边，却不覆盖纸页，也不要求读者频繁离开纸书。

## 核心功能

- 手机 OCR 持续识别书籍封面与当前页码
- 页边屏幕实时显示当前页面对应的读者批注
- 读者可直接在屏幕上表达赞同或不赞同
- 手机端支持标记灵感、保存草稿和发表批注
- 批注经审核后进入对应书页的公共页边
- 个人主页汇总批注、灵感与赞同记录
- 不同用户与阅读会话之间的状态相互隔离
- 屏幕支持扫码绑定、网络配对、在线状态与远程升级

## 使用流程

1. 打开众生行记网站并登录。
2. 首次使用时，扫描二维码绑定页边屏幕。
3. 点击“开始阅读”或底部“拍摄”按钮。
4. 架好手机，让书籍完整进入画面。
5. 展示封面，待系统识别书籍后打开正文。
6. 正常翻页，系统自动识别当前页码。
7. 页边屏幕同步显示当前页面的批注。
8. 在屏幕上对批注表示赞同或不赞同。
9. 在手机端标记灵感、保存草稿或撰写批注。
10. 批注审核通过后，会在其他读者翻到同一页面时出现。

## 技术方案

| 模块 | 技术与职责 |
| --- | --- |
| 书籍识别 | OpenCV 与 ORB 特征匹配识别已录入书籍 |
| 页码识别 | RapidOCR 提取当前页码 |
| 稳定性过滤 | 运动检测与多帧共识过滤翻页过程中的误识别 |
| 后端服务 | Python 与 SQLite 提供账号、设备、批注和审核服务 |
| 服务部署 | Docker 部署 Web 与视觉识别服务 |
| 页边终端 | ESP32-S3、LVGL 与触摸屏完成低干扰展示和交互 |
| 安全通信 | HTTPS、设备令牌与会话隔离完成云端通信 |

## 创新点

### 以书页为坐标的异步相遇

不是围绕整本书建立讨论区，而是让观点附着在具体页面上，在读者真正翻到这里时才出现。

### 不离开纸书的数字交互

数字内容由独立页边屏幕承载，不遮挡纸页，也不要求读者反复操作手机。

### 从“推荐内容”转向“遇见痕迹”

系统不急于猜测用户想看什么，而是让读者在阅读现场偶遇前人的观点，为知识探索保留意外感。

### 让馆藏随阅读生长

纸质内容保持不变，数字页边会随着读者的批注、回应与审核持续积累。

### 软硬件协同增强实体阅读

手机、云端与页边屏幕各自承担最适合的角色，共同形成完整而安静的阅读体验。

## 应用价值

- **图书馆共读**：围绕馆藏形成跨时间的页面级交流，让后来者看见此前读者的思考。
- **课程教材**：教师可在指定页面留下提示、问题与补充说明，学生也能回应或提交理解。
- **学术与专业阅读**：研究者可围绕具体页码积累解释、争议和关联资料。
- **阅读活动**：读书会不再只依赖读后讨论，也能保留成员阅读过程中的即时想法。
- **馆藏活化**：借助页边内容、阅读次数与互动痕迹，让长期沉睡的书重新被发现。
- **生活中的小惊喜**：随机出现的他人批注，为独自阅读带来不期而遇的共鸣、启发或分歧。

## 项目愿景

我们希望图书馆保存的不只是书，也包括人们如何读过这些书。

当每一次停留、疑问、联想和回应都能在对应的书页旁留下痕迹，纸质书便不再是一件沉默的馆藏，而会成为一条不断有人经过、不断长出新意义的路径。

**众生行记——书页不语，众生留下行迹。**
